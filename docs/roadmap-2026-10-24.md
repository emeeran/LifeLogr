# LifeLogr — Enhancement & Improvement Roadmap (2026-10-24)

Full sweep of the codebase (backend, frontend, desktop shell, docs, CI, packaging) to scope
improvements across four axes: broad overview, quality & hardening, new features, and
shipping/packaging. The codebase is unusually clean (zero TODO/FIXME markers in app code), so
the real scope lives in **unshipped work, explicit "deferred" lists in the project's own audit
doc, half-implemented features, and gaps between docs and reality** — not in marker-hunting.

> Companion to [audit-2026-10-18.md](audit-2026-10-18.md) (whose Addendum 1 "Deferred" list is
> the authoritative backlog this roadmap builds on).

Code is at **0.11.0** (all 4 version sources + a built `.deb`), but the changelog stops at
0.10.1 — a ~110-finding security/durability pass is sitting unreleased and undocumented.

---

## P0 — Ship what's already built (highest leverage, lowest effort)

1. **Backfill CHANGELOG for 0.11.0 and cut a release.** The Unreleased section is a complete,
   tested audit pass; the changelog ships in-app via "What's New", so the gap is user-visible.
   File: `CHANGELOG.md`.
2. **Resolve the uncommitted working-tree change** (removes per-selection font/size from the
   notes editor, +10/−71 across `EditorToolbar.vue`, `NoteEditor.vue`, `useRichTextEditor.ts`).
   The diff is clean — no orphaned references — but it silently removes a notes-only UX
   capability (per-selection fonts). Confirm intentional, then commit.
3. **Doc version-sync.** `docs/ARCHITECTURE.md`, `docs/BUILD_GUIDE.md`, `README.md`,
   `docs/manual/USER_MANUAL.md` all pin 0.10.1 with ~20 hardcoded artifact filenames. Fix by
   templating the version (build-time injection like `VITE_APP_VERSION`) or a `make docs-check`
   CI target.
4. **Delete or implement mobile.** `README.md` admits `mobile/` is "not yet implemented", yet
   `docs/manual/DEPLOYMENT.md` §6 documents a full Capacitor build and `scripts/build.sh`
   `build_mobile()` npm-inits a project on the fly. Also retire `ADR-006` (Whisper
   transcription) — the feature was removed and the user manual says speech-to-text is
   unavailable.

## P1 — Correctness & data-loss risks (quality/hardening)

5. **Bulk import is O(N) round trips + AI storm.** `backend/app/routers/entries.py` (import
   route) calls `EntryService.create()` per row → per-row commit plus a fire-and-forget
   `asyncio.create_task` per entry in `enrichment_service.py` with **no concurrency cap** — a
   large import schedules N simultaneous Ollama jobs. Fix: single transaction, bounded
   enrichment queue (semaphore), progress reporting.
6. **Re-add deleted test file.** `.pytest_cache/v/cache/lastfailed` references
   `tests/unit/test_sync_pollers.py` (2 failing tests) which no longer exists on disk — tests
   were deleted while red. Confirm nothing was dropped silently.
7. **Test the untested critical paths** (audit Part 5): FTS trigger sync (conftest creates FTS
   tables *without triggers* → tests silently hit the ILIKE fallback), schema-upgrade through
   `init_db` (zero coverage; `_drop_removed_feature_tables` unconditionally DROPs), untested
   services (`hashtag`, `enrichment_service`, `template_service`, `note_media_service`),
   untested routers (`box`, `dropbox`, `onedrive`, `video_notes`, `prompts`, `recordings`).
8. **Notes crash-safety on the frontend.** Notes autosave is deliberately Ctrl+S-only with
   router-guard protection, but a crash loses everything. Add a session-recovery draft buffer
   (localStorage mirror + restore prompt).
9. **Danger-endpoint hardening.** `POST /api/v1/entries/reset` needs only `{"confirm": "RESET"}`
   on an unauthenticated loopback API — any local process or loopback-hosted page can wipe the
   journal. Require the (already implemented, opt-in) `API_TOKEN` for destructive endpoints at
   minimum.
10. **Frontend test floor.** Only 20 vitest files vs 63 components; `useRichTextEditor`
    (undo/redo, shortcut map, format detection — the most complex logic in the app) is
    untested. Prioritize: `useRichTextEditor`, `useAutoSave`, `EditorToolbar`, settings tabs.
    Add non-Chromium e2e browsers.

## P2 — New features (highest user-visible value)

11. **Semantic search for notes.** No `NoteEmbedding` model exists; `search_service.py`
    docstring calls notes "keyword-only in v1". This is the single biggest capability gap in a
    journaling app that advertises hybrid search.
12. **Cloud sync merge for non-entry entities.** The only explicit "not implemented" in the
    codebase: `cloud_sync_service.py` logs "merge not implemented" and skips all media/tag/note
    ops on pull — the sync queue accepts them and silently drops them.
13. **Editor refactor + shared editor surface.** `NoteEditor.vue` (1,697 lines) and
    `EntryEditor.vue` (1,582) duplicate TTS wiring, media insert, tag autocomplete, dirty
    tracking, find/replace. The audit Addendum 1 already scoped `useEditorMedia`/`useEditorOcr`
    extraction — gate it on `useRichTextEditor` tests (P1 #10 first).
14. **Ollama model-pull observability.** `backend/app/routers/ai.py` pull-model is
    fire-and-forget — no job id, progress, cancellation, or error surfacing to the UI.
    Sibling: unwrap the synchronous `notify-send` spawn in `reminder_service.py` (the only
    unwrapped blocking call) and add a cross-platform notification fallback (currently
    Linux-only, silent failure elsewhere).
15. **TTS now-playing bar.** `stores/tts.ts` already exposes `currentTime`/`duration` "for a
    future now-playing bar (no UI in v1)" — the backend work is done.
16. **Virtualize `MediaTimelineView`.** Renders all items with plain `v-for` while
    `@tanstack/vue-virtual` is already a dependency and used in `TimelineView`/`NotesView`.
    Largest unbounded list in the app.
17. **Shortcut discoverability + command palette.** Add a `useHotkey` composable (global
    keydown listeners are currently scattered across 7 components, Ctrl+K double-bound), a
    shortcuts cheatsheet dialog, and consider evolving the Ctrl+K palette into a command
    palette.

## P3 — Shipping & packaging

18. **Auto-update + signing.** No Tauri updater config/signing keys (in-app "Check for updates"
    is check-only), no macOS notarization, no Windows Authenticode, no arm64 Linux/macOS builds
    (universal2 explicitly deferred in `build.yml` and audit Addendum 1). Tauri updater is the
    core gap.
19. **Release-artifact integrity.** No checksums/SBOM; Docker image not published to a registry; the web `.deb` (`scripts/build-web-deb.sh`) builds a venv over the network at install time — fragile and untested in CI.
20. **Misc dead code & a11y**: migrate 19 `errMsg.ts` shim call sites → `errorMessage.ts`, then delete the shim; drop legacy transcription columns (`models/recording.py`) in a schema-version bump; gitignore `desktop/src-tauri/gen|target`; lazy-load `MemorialTribute.vue` (732 lines + ~1.3MB asset in the settings chunk); a11y pass on icon-only buttons (`EditorToolbar` has 33 buttons, 0 aria-labels); remaining
    `window.confirm` uses → `ConfirmDialog`; `prefers-reduced-motion`; fix hardcoded `class="dark"` in `index.html` (FOUC).
